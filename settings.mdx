---
title: "Settings"
description: "This article describes how to create a plan viewer with Planpoint starting with the first module: the general settings."
---

<Note>**Prerequisite** You should have all your content already prepared. For more details about the content, please read the [checklist](/checklist).</Note>

<Steps>
  <Step title="Step 1">
    Click on the + New project button on the upper left side of the dashboard.

    <Frame>
      ![](https://i.postimg.cc/RVQ718SF/settings-1.jpg)
    </Frame>
  </Step>

  <Step title="Step 2">
    Assign a project name, address, choose the project type (sales, rental, land, commercial), and select whether you want to skip the floor or not. This allows you to jump directly from the project render to the unit you choose to view. This feature is typically used for small projects.

    <Frame>
      ![](https://i.postimg.cc/6QSbsS4Y/settings-2.jpg)
    </Frame>

    You can also copy settings from other projects. This allows you to set up projects faster when they have similar or identical configurations. If you have a promo code, you can enter it here as well.

    <Frame>
      ![](https://i.postimg.cc/T1S3nTK4/settings-3.jpg)
    </Frame>

    Choose the specific plan for this specific project. Plans are based on the number of **units per project.** Larger real estate projects require a larger monthly plan.

    <Frame>
      ![](https://i.postimg.cc/D0W2vRxG/settings-4.png)
    </Frame>
  </Step>

  <Step title="Step 3">
    The project is now created but empty. In your dahsboard, click on **details.**

    <Frame>
      ![](https://i.postimg.cc/hPcXbtZC/settings-5.png)
    </Frame>

    This will redirect you to the **settings** module, where you will find the following tabs:

    <Frame>
      ![](https://i.postimg.cc/VsGNMWM5/settings-6.png)
    </Frame>
  </Step>

  <Step title="Step 4">
    Under **details** you can do the following:

    * Define a cover image. This is the image that will appear in the card preview of the project in the dashboard and will also be your main building image. Please choose a high-resolution image, but no bigger than 1 MB. You can also choose a secondary project image, which you can use if you want to change the project’s main image.

    * Edit the project's name.

    * Turn the Skip Floor Step feature on or off.

    * If you wish, you can add the website URL of your project, which will redirect you to the project's website.

    * You can also add an internal URL for the project. This is intended for your marketing and sales teams.

    <Frame>
      ![](https://i.postimg.cc/g0hpT1gN/settings-7.png)
    </Frame>

    Pause or delete the project's subscription.

    <Frame>
      ![](https://i.postimg.cc/5Nd5Czz2/settings-8.png)
    </Frame>
  </Step>

  <Step title="Step 5">
    After finishing with the project details, move on to the **customization** tab. Here you can do the following:

    * Select the property type (Condominium, rental, townhouse, house, land, retail, office, commercial, industrial).

    * Turn on/off prices. When turned on, the plan viewer will show each unit's price.

    * Turn on/off availabilities. When turned on, the plan viewer will specify whether each unit is available or not.

    * You can choose which units to display based on their status. You can display all units, all units except sold units, or only available units.

    * Turn on/off the unit information freely. This includes inclusions, parking, orientation, bathrooms, descriptions, finishes and more.

    * Turn on/off the [Choice of Finishes](/custom-finishes) feature, letting visitors pick between different finish packages for a unit.

    * You can choose which filters to display in the plan viewer and drag them into your preferred order.

    <Frame>
      ![](https://i.postimg.cc/8zVj4Bp9/Clean-Shot-2026-09-28-at-14-29-39-2x.png)
    </Frame>

    * The Unit Display Fields section lets you choose which elements of a unit you want to display in the project. For example, if your project doesn’t have an orientation feature, you can hide it. Similarly, if the project doesn’t have a media gallery, you can hide that field as well.
    * The Engagement Features section lets you manage the interactive tools available in your Planpoint Viewer. You can quickly enable or disable features such as favorites, sharing, featured units, custom forms, custom buttons, sponsors, and Walk Score. For Custom Buttons, you can create multiple calls to action, choose where they appear, add an icon, localize them by language, and define what happens when users click them.

      <Frame>
        ![](https://i.postimg.cc/DZzBypZ8/Clean-Shot-2026-09-28-at-17-29-48-2x.png)
      </Frame>
    * Finishing this section, we can see everything related to enterprise. Here you can add the project to the enterprise you have already created. Learn more about the [enterprise feature](https://viewerdocs.planpoint.io/enterprise).

    <Frame>
      ![](https://i.postimg.cc/c4K18djb/Chat-GPT-Image-Sep-28-2026-05-50-09-PM.png)
    </Frame>
  </Step>
</Steps>

<Info>Keep in mind that you can always preview your work in progress by navigating to the settings module, under the **Style & Embed** tab</Info>

## Troubleshooting

Here's how to solve some common problems when setting up a project.

<AccordionGroup>
  <Accordion title="Why can't I start a new project?">
    Please remember to add a credit card to your profile before initiating a project.
  </Accordion>

  <Accordion title="Can I change the monthly plan for a project?">
    Yes, you can change a monthly plan for a project only if it's a **rental** one. Rental projects are based in vacant units.
  </Accordion>

  <Accordion title="How can I connect my CRM to Planpoint?">
    For any connections, please contact us via support @ planpoint.io.
  </Accordion>
</AccordionGroup>
