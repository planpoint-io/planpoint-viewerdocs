---
title: "Choice of Finishes"
description: "Let buyers pick between different finish packages (kitchen, bathroom, and more) directly in the plan viewer"
---

The **Choice of Finishes** feature lets you create finish packages (for example "California", "Provence", "Kansai") made up of cover photos and thumbnails for different rooms, and apply them to your units. Visitors can then switch between the available finish options directly from the unit page in the viewer.

<Steps>
  <Step title="Step 1 - Turn on the feature">
    Go to your project's **Settings** module, under the **Customization** tab, and enable the **Choice of finishes** checkbox.

    <Note>
      This checkbox only controls whether the feature is visible to visitors. You still need to create at least one finish set and apply it to a unit for the button to appear.
    </Note>
  </Step>
  <Step title="Step 2 - Create a finish set">
    Go to your project's content page, open the **Media** tab, then the **Custom finishes** sub-tab.

    Click **Add new** to create a finish set:

    - Give it a name (this is what you'll pick from when applying it to units, e.g. "Californie").
    - For each room (Kitchen, Bathroom, General, etc.), upload a cover photo and a thumbnail for every finish option you want to offer.

    Cover photos must be a PNG or JPG under 1.5 MB. If your source files are larger, resize/compress them before uploading.
  </Step>
  <Step title="Step 3 - Apply a finish set to units">
    From the same **Custom finishes** tab, select one or more units and apply the finish set you created, the same way you would apply any other asset from the Media Gallery.

    <Note>
      If a unit already has a finish set applied and you're re-applying one (for example, after editing it), turn on **Replace** before applying. Otherwise the new tabs are added on top of the existing ones instead of replacing them, which can duplicate options for that room.
    </Note>
  </Step>
</Steps>

## What visitors see

Once a unit has at least one finish option configured and the feature is enabled for the project, visitors see a **Choice of finishes** button on that unit's page. Clicking it opens a room picker and a swatch/thumbnail selector so they can preview each finish option's cover photo before closing the panel.
